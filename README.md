# Folheto

React com Vite, JavaScript/JSX e Tailwind CSS. Sem TypeScript.

## Executar

```sh
npm install
npm run dev
```

No PowerShell com scripts bloqueados, use `npm.cmd` no lugar de `npm`.

## Produção

```sh
npm run build
npm run preview
```

Os estilos são definidos exclusivamente por classes Tailwind no JSX. O arquivo
`src/tailwind.css` contém somente o import do Tailwind, sem regras CSS próprias.
